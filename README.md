# Sistema de Livro e Conta Bancária

Sistema de gerenciamento de leitura e conta bancária desenvolvido em **Python**, com o objetivo de praticar conceitos fundamentais de **Programação Orientada a Objetos (POO)**.

## Objetivo

Desenvolver um sistema simples para acompanhar a leitura de um livro e realizar operações bancárias, aplicando conceitos de POO na prática.

## Conceitos utilizados

- Classes e objetos
- Encapsulamento
- Construtores (`__init__`)
- Atributos e métodos
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`while`)
- Entrada e saída de dados (`input` e `print`)

## Classes

O sistema possui:

- `livro` — gerenciamento das informações e do progresso de leitura
- `banco` — gerenciamento dos dados da conta bancária e do saldo

## Funcionalidades

- Abrir livro e consultar a página atual
- Avançar páginas durante a leitura
- Exibir o progresso da leitura
- Realizar depósitos
- Realizar saques
- Consultar saldo bancário
- Exibir extrato da conta
- Menus interativos pelo console

## Tecnologias

- Python
- Visual Studio Code
